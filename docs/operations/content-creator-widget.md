# Content Creator widget

The authenticated YouTube backoffice draft list offers an explicit
**Open Content Creator** button. It mounts the existing public ElevenLabs agent
on request only. No microphone is requested, message sent or call started by the
website. The widget retains the provider’s own disclosure, recording agreement,
text mode and microphone controls. The integration sends no backoffice records.

The public agent remains public and its existing settings and usage limits
are unchanged. Backoffice authorization protects the website, not external
access to the public agent. The integration adds no quotas, secrets, budget
service, or database bindings.

`commercial/src/scripts/sales/vendor/elevenlabs-public-widget.mjs`.
