Sources & definitions

Completed
Tasks whose Linear state type is completed. A Done task does not establish production deployment.
Remaining
Tasks in Backlog, Todo, In Progress or In Review. Archived tasks keep their recorded state.
Completion rate
Completed ÷ (completed + remaining). Canceled and duplicate issues are excluded from both numerator and denominator. Each parent task and subtask counts as one task. No effort estimates are available.
Time series
Recorded daily state intervals for the tasks in the current projects. Reopened tasks are included. Earlier project membership and tasks since deleted or moved out are not reconstructed. Today ends at the snapshot time.
Coverage
Code connections
Graphify relationships are grouped by source file. The map shows connections without direction. Dashed connections include inferred edges. MR SAASy uses a bounded Planning and Workslip view from Graphify Cloud; Tradey uses a local Graphify code and SQL snapshot. Code graphs do not establish runtime behavior, test coverage or task completion.
